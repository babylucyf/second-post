# Second Post: returns portal concept

Clickable demo of Second Post, a returns portal concept for small UK Shopify clothing brands, shown with Linden Row, a demo brand.

Static site, no build step. Open `index.html` or deploy the folder to Vercel as a static project.

Concept project by Ugonwa Ohagwasi. All orders, dates and amounts are made up. Royal Mail, InPost and Evri are named as real UK carriers and are not affiliated.
